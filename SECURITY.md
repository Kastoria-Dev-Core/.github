# Security Policy

## Reporting a vulnerability

Please do not open a public issue for security problems.

Use GitHub's private vulnerability reporting instead: open the affected repository, go to the **Security** tab and click **Report a vulnerability**.

Include:

- The affected repository and version or commit
- Steps to reproduce
- The possible impact

We will acknowledge the report as soon as we can and keep you updated until it is resolved.

## Supported versions

Only the latest version on the default branch of each repository receives fixes.
