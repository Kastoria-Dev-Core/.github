# .github

Organization-wide community files for [Kastoria Dev Core](https://github.com/Kastoria-Dev-Core).

- `profile/README.md`: the organization profile page
- `CONTRIBUTING.md`, `CODE_OF_CONDUCT.md`, `SECURITY.md`: default community health files for every repo
- `ISSUE_TEMPLATE/`, `PULL_REQUEST_TEMPLATE.md`: default issue and PR templates
- `brand/`: logo, avatar and social preview image
